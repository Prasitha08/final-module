# Module 06 – Final Data Science Project

## Project Title
**Student Performance Analysis & Score Prediction**

## Project Overview
This is an end-to-end Data Science project using a real-world student performance dataset.
The project covers data collection, data cleaning, exploratory data analysis, visualization,
feature preparation, machine learning, model evaluation and interpretation.

## Objectives
- Analyze factors related to student academic performance.
- Create meaningful visualizations and insights.
- Build machine learning models to predict final mathematics scores.
- Compare model performance.
- Prepare the project as a portfolio-ready GitHub repository.

## Dataset
UCI Machine Learning Repository – Student Performance dataset.

The notebook loads the mathematics performance CSV from the public UCI repository.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab

## ML Models
1. Linear Regression
2. Random Forest Regressor

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## How to Run
Open `Student_Performance_Final_Project.ipynb` in Google Colab and select:

**Runtime → Run all**

The notebook downloads the public dataset automatically.
